⚡ 빠른 입력 BETA

먹은 것을 그대로 적거나 붙여넣으세요. 줄마다 날짜·끼니를 앞에 쓰면 알아서 나눠요.

날짜·끼니를 안 쓴 줄은 위에서 고른 날짜·끼니로 들어가요. 알아듣기 뒤에도 줄마다 바꿀 수 있어요.

하나씩 입력

처음 보는 음식이에요. 포장지의 1단위당 칼로리를 넣으면 다음부터 자동으로 계산돼요.

음식을 고르면 칼로리가 계산돼요.

⚡ 빠른 입력 BETA

한 운동을 그대로 적거나 붙여넣으세요. 시간·세트·무게·횟수·경사/속도를 알아서 나눠요.

날짜를 안 쓴 줄은 아래 '하나씩 입력'의 날짜로 들어가요. '오늘·어제'도 알아들어요.

하나씩 입력

헬스는 '헬스 + 총 시간'으로 한 번, 종목은 시간 없이 세트·무게·횟수로 따로 넣으면 돼요.

이 기간이 걸친 주는 '회복 주간'으로 표시되고, 캐릭터가 담요를 덮고 쉬어요.

페이지에서 넣은 기록 0

    여기서 넣은 기록은 바로 게임에 반영돼요. Claude에게 "다이어트 RPG 동기화해줘"라고 하면 계산표에도 옮겨 적고, 대기 중인 칼로리도 계산해 둘게요.
